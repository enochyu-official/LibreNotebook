# LibreNotebook

*[LibreNotebook](https://librenotebook.enochyu.com/)*
is Enoch Yu's giant and free notebook.

## About

*LibreNotebook* is a personal notebook that I write as
I explore different topics of my interest. I personally learn
the best when I explain the contents, so I naturally write
my notes as if I am explaining the topics to other people.
Although *LibreNotebook* reflects my fields of interest,
I strive to include thorough insights whenever possible.

Having said that, *LibreNotebook* is not meant to replace
textbooks nor dedicated resources. Rather, it is intended
to encourage and accelerate open education by returning
the knowledge and skills that I received from public resources.
For anyone interested in the topics in the notes, I hope
*LibreNotebook* serve as a useful resource.

## Access

[The most recent draft](https://archive.enochyu.com/LibreNotebook.pdf)
is available as a PDF format. There is also a web version hosted at
[librenotebook.enochyu.com](https://librenotebook.enochyu.com/),
which is updated weekly.
