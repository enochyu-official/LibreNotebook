# LibreNotebook

LibreNotebook is a giant and free notebook that anyone can read and
modify. The most recent draft is available
[HERE](https://archive.enochyu.com/mathematics/pdf/26100.pdf)!
The purpose is to inspire and accelerate open education as a
way of returning the blessings that we received from public
educational resources.
